# 一、系统概念

完整物理系统：

```text
UAV：6 DOF
x / y / z / roll / pitch / yaw

机械臂：3 DOF
J2 / J3 / J4
```

共 9 DOF。

局部伐枝任务主要关注：

\[
[\ UAV_{yaw},\ J2,\ J3,\ J4]
\]

功能分工：

```text
UAV x/y/z
→ 把机械臂送到目标附近

UAV yaw
→ 调整机械臂工作平面对准树枝

J2/J3
→ 链锯到达切割点

J4
→ 调整链锯滚转方向和切割姿态
```

# 二、运动学与动力学

运动学主要解决：

```text
关节怎么转
→ 末端在哪里、朝哪里
```

动力学主要解决：

```text
为了这样运动
→ 电机需要输出多大力矩
→ 重力、摩擦、惯性、耦合、外力有什么影响
```

当前 Step13 先重点解决运动学。

动力学主要留到：

```text
实机关节选型
重力补偿
高速运动
链锯接触力
UAV–机械臂耦合控制
```

# 四、FK 与 IK

## 正运动学 FK

```text
J2/J3/J4
↓
链锯位置 + 姿态
```

即：

\[
x=f(q)
\]

## 逆运动学 IK

```text
目标位置 + 姿态
↓
J2/J3/J4
```

一个目标可能：

```text
多个解
唯一解
无解
```

因此真正需要的是：

> 满足关节限制、碰撞、奇异性和切割任务要求的安全解。

# 五、Jacobian、秩与奇异位形

Jacobian：

> 描述当前姿态附近，关节微小变化会导致末端发生多大的位置/姿态变化。

\[
\dot x = J(q)\dot q
\]

秩：

> 当前还能独立控制多少个运动方向。

奇异位形：

> 某些特殊几何姿态使 Jacobian 丢秩，从而使末端某些独立瞬时运动能力丢失。

需要区分：

```text
关节极限 ≠ 奇异位形
目标不可达 ≠ 奇异位形
```

靠近奇异位形时，可能出现：

```text
末端只要求小幅运动
↓
反算得到异常大的关节速度
```

# 六、三级工作空间

建议建立：

\[
W_{\mathrm{preferred}}
\subset
W_{\mathrm{safe}}
\subset
W_{\mathrm{reachable}}
\]

### 可达区

```text
有IK解
```

### 安全区

```text
无碰撞
不过关节极限
远离明显奇异区域
满足旋翼/树冠安全距离
```

### 优选区

在安全基础上进一步要求：

```text
关节余量大
远离奇异位形
末端不会过度靠近飞机
机械臂不会伸得太远
质心偏移较小
力矩臂较小
Camera + MID360 可见性好
链锯姿态适合切割
```

核心思想：

> 可达不等于安全，安全也不等于优选。

---

# 七、安全裕度

后续可建立：

\[
S \in [0,1]
\]

综合：

```text
关节余量
奇异性裕度
碰撞距离
机械臂伸展程度
质心偏移 / 力矩臂
感知可见性
切割姿态质量
```

决策逻辑：

```text
不可达
→ UAV重新规划

可达但安全裕度低
→ 换IK解 / UAV重新定位

可达且安全冗余度大
→ 执行动作
```

# 九、核心研究思想

推荐表述：

> **UAV 主动重定位，使目标进入机械臂具有较大安全裕度和较高操作性能的优选工作空间，再执行切割。**

其本质不是简单：

```text
够不到
→ UAV挪一下
```

而是：

```text
目标不可达 / 当前构型不安全
↓
调整 UAV x/y/z/yaw
↓
改变机械臂基座相对于目标的位置
↓
重新构造目标与机械臂工作空间的关系
↓
重新做可达性分析与IK
↓
使目标进入优选工作空间
↓
执行切割
```

# 十一、课题建议表述

**面向树木智能伐枝的 UAV–机械臂多约束协同可达性分析与安全重定位规划**

可向导师概括为：

> 面向非结构化树冠环境，在枝条方向、切割平面、链锯姿态、树冠碰撞、旋翼安全区、机械臂工作空间、奇异性及感知可见性等多重约束下，对目标切割点进行安全可达性评价。当目标不可达或安全裕度不足时，通过 UAV 主动重定位改变机械臂基座位姿，使目标进入机械臂的优选工作空间，再进行逆运动学求解和切割执行。

# 十二、下一步实施路线

```text
1. 建立机械臂坐标系
2. 建立正运动学 FK
3. Gazebo 验证 FK
4. 建立逆运动学 IK
5. 生成可达工作空间
6. 加入关节限制和碰撞约束
7. 加入奇异性 / 可操作度
8. 建立安全工作空间
9. 建立优选工作空间与安全裕度
10. 接入 UAV 主动重定位
```

一句话总结：

> **当前目标不是让机械臂“够得到”即可，而是通过 UAV–机械臂协同，使目标进入安全裕度大、操作性能高、感知条件好、切割姿态合适的工作区域。**
