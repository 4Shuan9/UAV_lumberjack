> 用途：阶段性学习笔记、课题讨论、向导师汇报前的知识梳理  
> 当前主题：机械臂运动学、安全工作空间、奇异性、UAV–机械臂协同可达性与安全重定位规划

## 1. 系统对象与自由度

本项目研究对象为：

```text
UAV
+
3自由度机械臂
+
链锯末端执行器
+
RGB相机
+
MID360类3D LiDAR
```

### 1.1 完整物理系统自由度

UAV 本体具有 6 个自由度：

```text
x, y, z, roll, pitch, yaw
```

机械臂具有 3 个关节自由度：

```text
J2, J3, J4
```

因此完整构型变量可写为：

\[
q_{\mathrm{whole}}
=
[x,\ y,\ z,\ \phi,\ \theta,\ \psi,\ q_2,\ q_3,\ q_4]^T
\]

即完整系统为 **9 DOF（6+3）**。

### 1.2 局部伐枝任务中的重点自由度

在局部伐枝规划中，UAV 的 roll / pitch 主要由飞控用于姿态稳定，因此可重点考虑：

\[
[\psi_{\mathrm{UAV}}, q_2, q_3, q_4]
\]

自然语言描述为：

```text
UAV x/y/z
→ 将整套机械臂送到目标树枝附近

UAV yaw
→ 调整机械臂工作平面，使其对准树枝

J2/J3
→ 将链锯送到具体切割点

J4
→ 调整链锯自身滚转方向和切割姿态
```

需要注意：这并不代表整个系统只有 4 个自由度，而是表示这 4 个变量是局部末端任务规划中的主要构型变量。

## 2. 机械臂运动学与动力学

### 2.1 运动学研究什么

运动学主要研究：

> 关节如何运动，末端执行器最终位于哪里、朝向哪里。

核心内容包括：

- 正运动学 FK
- 逆运动学 IK
- Jacobian
- 奇异位形
- 可达工作空间
- 安全工作空间
- 轨迹规划

---

### 2.2 动力学研究什么

动力学研究：

> 为了让机械臂以指定角度、速度、加速度运动，需要多大的关节力矩，以及重力、惯性、摩擦、耦合和外力如何影响运动。

典型动力学方程为：

\[
M(q)\ddot q
+
C(q,\dot q)\dot q
+
G(q)
+
F(\dot q)
=
\tau+\tau_{\mathrm{ext}}
\]

其中：

| 项 | 含义 |
|---|---|
| \(q\) | 关节角 |
| \(\dot q\) | 关节速度 |
| \(\ddot q\) | 关节加速度 |
| \(M(q)\ddot q\) | 惯性项 |
| \(C(q,\dot q)\dot q\) | 科氏力/离心耦合 |
| \(G(q)\) | 重力项 |
| \(F(\dot q)\) | 摩擦项 |
| \(\tau\) | 电机输出力矩 |
| \(\tau_{\mathrm{ext}}\) | 外力对应的等效关节力矩 |

即使机械臂已经到达目标位置，只要重力对关节仍产生力矩，关节电机仍需要输出保持力矩。

例如机械臂水平伸出：

```text
q̇ = 0
q̈ = 0
```

但仍可能存在：

```text
G(q) ≠ 0
```

因此仍需要电机输出力矩保持姿态。

### 2.3 当前项目为什么暂时不深入动力学

当前 Gazebo 中采用位置控制，Gazebo 物理引擎已经在仿真层处理机械运动。

因此 Step13 当前重点是：

```text
坐标系
→ FK
→ IK
→ 工作空间
→ 奇异性
→ 安全约束
→ 自动规划
```

动力学在以下阶段会更加重要：

- 实机关节电机选型
- 重力补偿
- 高速机械臂运动
- 链锯接触/切割外力
- 机械臂运动对 UAV 姿态的反作用
- UAV–机械臂耦合动力学
- 力控制、阻抗控制

因此更准确的结论是：

> 当前并非“不需要动力学”，而是暂时不需要把完整动力学模型作为主要控制对象；实机与高阶协同控制阶段再重点研究。

## 3. 坐标系统一与目标点表达

感知系统得到的目标最初可能位于：

```text
camera_link
或
MID360 / LiDAR frame
```

为了进行机械臂逆运动学，目标应通过 ROS2 TF 统一转换到：

```text
base_link
```

例如：

\[
{}^{B}p_t =
[x_B,y_B,z_B]^T
\]

表示：

> 目标切割点相对于 UAV 机体坐标系的位置。

整个链路可表示为：

```text
Camera / MID360
      ↓
目标检测与三维定位
      ↓
ROS2 TF
      ↓
base_link
      ↓
机械臂规划与IK
```

树枝在 world/map 坐标系中可近似静止，而 UAV 会不断运动，因此：

```text
树枝在 world/map 中的位置
≈ 基本不变

UAV 位姿
= 实时变化

树枝相对于 base_link 的位置
= 实时变化
```

因此控制过程中应实时更新：

\[
{}^{B}p_t(t)
\]

## 4. 正运动学 FK

### 4.1 定义

正运动学回答：

> 已知关节角，末端执行器在哪里、朝向哪里？

数学形式：

\[
x=f(q)
\]

例如：

```text
输入：
J2, J3, J4

输出：
链锯末端位置 [x,y,z]
+
末端姿态 [roll,pitch,yaw]
```

---

### 4.2 最简单二维二连杆模型

设：

- \(L_1\)：第一根连杆长度
- \(L_2\)：第二根连杆长度
- \(q_2\)：第一关节角
- \(q_3\)：第二关节相对第一根杆的角度
- \(x,z\)：末端位置

二维二连杆：

```text
         P(x,z)
          ●
         /
       L2
       /
      ●  J3
     /
   L1
   /
  ●
 J2
```

其末端位置为：

\[
x=L_1\cos q_2+L_2\cos(q_2+q_3)
\]

\[
z=L_1\sin q_2+L_2\sin(q_2+q_3)
\]

理解方式：

第一根杆：

\[
x_1=L_1\cos q_2,\qquad
z_1=L_1\sin q_2
\]

第二根杆的绝对角度为：

\[
q_2+q_3
\]

因此：

\[
x_2=L_2\cos(q_2+q_3)
\]

\[
z_2=L_2\sin(q_2+q_3)
\]

最后：

\[
x=x_1+x_2,\qquad z=z_1+z_2
\]

## 5. 逆运动学 IK

### 5.1 定义

逆运动学回答：

> 已知目标末端位置或姿态，反求机械臂关节变量。

即：

```text
目标位置 / 姿态
       ↓
      IK
       ↓
J2, J3, J4
```

更学术地表述：

> 逆运动学是在给定末端执行器期望位置或姿态的条件下，求取满足该目标的关节变量。对于给定目标，逆运动学可能存在多个解、唯一解或无解，因此工程应用中不仅要求“有解”，还需要进一步筛选满足关节限制、碰撞约束、奇异性约束及任务要求的安全解。

### 5.2 多解、无解与安全解

同一个目标点可能存在多个关节构型：

```text
肘上
肘下
```

因此：

```text
目标点
↓
多个 IK 候选解
↓
安全性与性能评价
↓
选择最优解
```

目标也可能根本不可达，此时不存在 IK 解。

### 5.3 本项目中仅有 [x,y,z] 还不够

由于 J4 主要用于调整链锯自身姿态，因此未来目标应包括：

```text
cut_point
branch_direction
cutting_plane
approach_direction
desired_saw_orientation
```

最终应实现：

```text
目标位置 + 目标姿态
        ↓
       IK
        ↓
   J2 J3 J4
```

## 6. Jacobian

### 6.1 Jacobian 的本质

Jacobian 不是“关节角对应末端位置的表”。

正运动学：

\[
x=f(q)
\]

Jacobian：

\[
J(q)=\frac{\partial f(q)}{\partial q}
\]

它描述：

> 在当前姿态附近，关节变量发生微小变化时，末端位置或姿态会发生多大的变化。

速度关系：

\[
\dot x=J(q)\dot q
\]

自然语言：

```text
关节速度
q̇
 ↓
Jacobian
 ↓
末端速度
ẋ
```

可以把 Jacobian 理解为：

> 多输入、多输出函数的“导数矩阵”。

---

## 7. 秩 Rank

秩可以先直观理解为：

> 当前还能独立控制多少个运动方向。

例如二维末端正常能独立控制：

```text
X方向
Z方向
```

则可以理解为有两个独立运动方向。

如果某种特殊姿态导致其中一个方向无法独立运动：

```text
rank: 2 → 1
```

表示损失了一个独立运动能力。

---

## 8. 奇异位形

### 8.1 定义

奇异位形是指：

> 机械臂进入某种特殊几何姿态后，Jacobian 矩阵秩降低，从而使末端某些独立瞬时运动能力消失。

### 8.2 三个概念必须区分

```text
关节极限
→ q 达到允许的 min/max

目标不可达
→ 不存在满足目标的 IK 解

奇异位形
→ Jacobian 丢秩
→ 某些瞬时运动方向丢失
```

因此：

> 奇异位形并不等于机械关节达到极限位置。

### 8.3 靠近奇异位形为什么危险

逆速度关系可写为：

\[
\dot q=J^{-1}\dot x
\]

靠近奇异位形时，\(J\) 接近不可逆，为实现一个并不大的末端速度，反算出的关节速度可能异常增大。

自然语言：

```text
末端只要求小幅运动
↓
数学反算
↓
J2/J3可能需要非常大的、互相补偿的关节速度
```

完全奇异时：

```text
J^-1 不存在
```

因此可以将奇异位形理解为：

> 某些瞬时运动方向消失；靠近奇异位形时，为实现某些末端运动，求解结果可能出现不符合正常工程要求的极大关节速度。

## 9. 工作空间

### 9.1 可达工作空间

记作：

\[
\mathcal W_{\mathrm{reachable}}
\]

定义为：

> 在允许的关节范围内，末端执行器能够到达的全部空间。

### 9.2 可达不等于安全

某一点即使 IK 有解，也可能存在：

- J2/J3/J4 接近关节极限
- 接近奇异位形
- 机械臂或链锯过度靠近机体
- 机械臂进入旋翼危险区
- 机械臂伸展过远
- UAV 系统质心明显偏移
- 对 UAV 产生较大附加力矩臂
- 离树冠太近
- Camera / MID360 可见性较差
- 链锯姿态不适合切割

因此“可达”只是第一层条件。

---

## 10. 三级工作空间

建议将工作区域划分为三个层级：

\[
\mathcal W_{\mathrm{preferred}}
\subset
\mathcal W_{\mathrm{safe}}
\subset
\mathcal W_{\mathrm{reachable}}
\]

### 10.1 可达工作空间

\[
\mathcal W_{\mathrm{reachable}}
\]

条件：

```text
存在 IK 解
```

### 10.2 安全工作空间

\[
\mathcal W_{\mathrm{safe}}
\]

在可达基础上要求：

- 无机械碰撞
- 关节不过限
- 不进入明显奇异区域
- 满足 UAV–树冠安全距离
- 满足旋翼安全区域

### 10.3 优选工作空间

\[
\mathcal W_{\mathrm{preferred}}
\]

进一步要求：

- 离关节极限有较大余量
- 远离奇异位形
- 末端不靠 UAV 过近
- 机械臂不过度伸展
- UAV 质心偏移较小
- 对 UAV 的附加力矩臂较小
- Camera + MID360 具有较好可见性
- 链锯姿态适合切割

因此目标不是简单“能够碰到树枝”，而是：

> 在具有较大安全裕度和较高操作性能的区域完成切割。

## 11. 安全裕度与操作性能评价

相比只定义：

```text
safe = true / false
```

后续可建立连续安全裕度：

\[
S\in[0,1]
\]

例如：

\[
S=
f(
S_{\mathrm{joint}},
S_{\mathrm{sing}},
S_{\mathrm{collision}},
S_{\mathrm{extension}},
S_{\mathrm{visibility}},
S_{\mathrm{cut}}
)
\]

其中：

| 指标 | 含义 |
|---|---|
| \(S_{\mathrm{joint}}\) | 关节距离极限的余量 |
| \(S_{\mathrm{sing}}\) | 奇异性裕度 / 可操作度 |
| \(S_{\mathrm{collision}}\) | 对机体、旋翼、树冠的安全距离 |
| \(S_{\mathrm{extension}}\) | 机械臂伸展程度、质心偏移和力矩臂 |
| \(S_{\mathrm{visibility}}\) | Camera + MID360 对目标的可观测性 |
| \(S_{\mathrm{cut}}\) | 当前链锯姿态对切割任务的适合程度 |

规划逻辑可以为：

```text
不可达
→ UAV重新规划

可达但安全裕度低
→ 重新选择IK解 / UAV重新定位

可达且安全裕度足够
→ 执行动作
```

具体阈值应由后续仿真和实机实验确定，而不是提前人为固定。

## 12. UAV 主动重定位

普通固定机械臂：

```text
目标超出工作空间
↓
不可达
↓
任务失败或需要人工调整
```

本项目中的 UAV–机械臂系统具有移动基座，因此：

```text
目标不可达 / 当前构型不安全
↓
调整 UAV x/y/z/yaw
↓
机械臂基座位置发生变化
↓
机械臂工作空间在世界中被重新配置
↓
重新计算目标相对于 base_link 的位置
↓
重新进行可达性判断与 IK
```

其核心研究思想可表述为：

> **通过 UAV 主动重定位，使目标进入机械臂具有较大安全裕度和较高操作性能的优选工作空间，再执行切割。**

这比“够不到就向前飞一点”更准确。

本质上是：

> 利用 UAV 的移动基座能力，主动重构机械臂相对于目标的工作空间。


## 15. 课题的学术化表述

### 15.1 建议课题名称

**面向树木智能伐枝的 UAV–机械臂多约束协同可达性分析与安全重定位规划**

另一种表达：

**考虑切割任务约束与感知可见性的空中机械臂协同可达性与安全重定位方法**

### 15.2 研究问题描述

针对无人机搭载机械臂执行树木伐枝任务过程中存在的目标空间分布复杂、机械臂局部工作空间受限、树冠环境碰撞风险高及切割姿态约束强等问题，研究一种考虑切割任务约束与感知可见性的 UAV–机械臂协同可达性分析与安全重定位规划方法。

该方法以目标枝条三维位置、枝条空间方向及候选切割平面为任务输入，综合考虑链锯末端切割姿态、接近方向、机械臂关节约束、安全工作空间、奇异位形、飞行器与树冠安全距离、旋翼安全区域以及视觉–激光感知可见性等多重约束，对当前 UAV 位姿下目标切割点的安全可达性进行评估。

当目标位于机械臂安全可达工作空间内时，通过逆运动学求取满足切割姿态与安全约束的机械臂关节配置；当目标不可达、逆运动学无解，或候选解存在碰撞、奇异性、过度伸展及感知退化风险时，通过调整 UAV 空间位置及航向角重新配置机械臂基座位姿，并实时更新目标在机体坐标系下的相对位置，重新进行可达性分析与逆运动学求解。

最终形成：

```text
UAV 大范围机动 / 粗定位
+
机械臂局部精确操作
```

相结合的协同规划机制。

## 17. 当前阶段最重要的结论

1. 完整 UAV–机械臂系统可视为 9 DOF 系统。
2. 局部伐枝规划中重点关注 UAV yaw + J2/J3/J4。
3. 感知目标应通过 ROS2 TF 统一到 `base_link`。
4. FK 是“关节角 → 末端位置/姿态”。
5. IK 是“目标位置/姿态 → 关节角”。
6. Jacobian 是关节局部变化与末端局部运动之间的映射。
7. Jacobian 秩降低意味着独立运动能力减少。
8. 奇异位形不等于关节极限。
9. 可达不等于安全，安全也不等于优选。
10. 需要从可达工作空间进一步建立安全工作空间和优选工作空间。
11. UAV 的移动基座能力使“不可达”不再意味着任务结束，而可以通过重定位重新构造机械臂与目标之间的几何关系。
12. 本课题的核心思想为：

> **UAV 主动重定位，使目标进入机械臂具有较大安全裕度和较高操作性能的优选工作空间，再执行切割。**
